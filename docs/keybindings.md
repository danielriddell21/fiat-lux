# Key bindings

| Key                          | Action                              |
| ---------------------------- | ----------------------------------- |
| `q` / `ctrl-c` / `esc`       | Quit                                |
| `space`                      | Pause / resume                      |
| `tab` / `shift-tab`          | Focus next / previous agent         |
| `ctrl-tab` / `ctrl-shift-tab` | Focus next / previous world        |
| `s`                          | Save world to the configured `--db` |
| `m`                          | Memory inspector (focused agent)    |
| `?`                          | Help overlay                        |
| `n`                          | Debug: create a random entity       |
| `x`                          | Debug: destroy the newest entity    |
| `r`                          | Debug: relate the two newest        |
| `t`                          | Debug: advance the tick             |

The debug bindings exist mainly to exercise the TUI without spinning up
a real brain.
